# Getting started with loyalty

Clients collect points with every purchase and spend them on rewards.

* Open the [rewards page](route:acme.loyalty.rewards) to see what clients can redeem.
* Find out [how points are earned](points.md) before you promise anything to a client.
* Managers: [set the reward limits](admin/limits.md).
