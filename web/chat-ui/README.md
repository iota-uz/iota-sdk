# Shared Solid chat UI

`@iota-uz/sdk/chat-ui` owns the reusable composer, conversation history, streaming state machine, artifacts, tables, charts, citations, HITL forms and session navigation UI. Host-specific authorization and agent workflows remain in the consuming Go module.

Import `@iota-uz/sdk/chat-ui/styles.css` alongside the host stylesheet. Components render under the standard Solid client host, whose portal registry owns modal/drawer/toast surfaces, focus restoration and background locking.

```tsx
import { onCleanup } from 'solid-js'
import { useClientHost } from '@iota-uz/sdk/solid'
import { biChatHTTPConfigFromRoute } from '@iota-uz/sdk/client-host'
import { ChatSession, IotaContextProvider, ManagedHttpDataSource } from '@iota-uz/sdk/chat-ui'
import '@iota-uz/sdk/chat-ui/styles.css'

function Screen(props) {
  const host = useClientHost()
  const source = new ManagedHttpDataSource(biChatHTTPConfigFromRoute(props.route, host.session), host.session)
  onCleanup(() => source.dispose())
  return <IotaContextProvider context={props.route.initial.appletContext}>
    <ChatSession dataSource={source} sessionId={props.sessionId} />
  </IotaContextProvider>
}
```

Mutable values are Solid props/getters; `ChatSession` preserves its state owner when the session URL changes. `ManagedHttpDataSource.dispose()` aborts pending RPC/uploads and settles managed stream consumers. Ordinary cancel closes the active stream while keeping the mounted data source usable.

The RPC schema is generated by the canonical BiChat applet tooling. `pnpm --dir web/chat-ui rpc:sync` copies that generated schema; package builds reject drift. Run `pnpm --dir web/chat-ui test` and `pnpm --dir web/chat-ui build:package`; real integration journeys live in the Granite browser suite.
